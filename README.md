
========================================
자동매매사이트 초간단 설명
========================================

■ 정의
자동매매사이트는 사람이 직접 매매하지 않고,
미리 설정한 조건에 따라 자동으로 매수·매도하는 시스템이다.

즉,
“이 가격이 되면 사고, 저 가격이 되면 판다”
라는 규칙을 프로그램이 24시간 대신 실행한다.


========================================
■ 기본 작동 구조
========================================

1. 거래소 API 연결
2. 매매 전략(조건식) 설정
3. 실시간 시세 데이터 수집
4. 조건 충족 시 자동 주문 실행
5. 수익/손실 기록 및 관리


========================================
■ 주요 구성 요소
========================================

- 시세 데이터 수집 (REST / WebSocket)
- 매매 전략 로직
- API Key (주문 권한)
- 자산 관리 시스템
- 수익 분석 대시보드


========================================
■ 전략 예시
========================================

- 이동평균선 돌파 매매
- RSI 과매수/과매도 전략
- 일정 % 수익 도달 시 자동 익절
- 일정 % 손실 시 자동 손절
- 특정 시간대 자동 매매


========================================
■ 장점
========================================

- 24시간 감정 없이 매매 가능
- 빠른 주문 실행
- 여러 종목 동시 관리 가능


========================================
■ 단점
========================================

- 전략이 잘못되면 자동 손실 발생
- API 오류 및 서버 문제 위험
- 급격한 시장 변동 대응 한계


========================================
■ 한 줄 요약
========================================

자동매매사이트는
사람의 매매
